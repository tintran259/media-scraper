Chế độ khách

Chế độ khách chỉ lấy được bình luận công khai (khoảng 60–70%). Đăng nhập để lấy đầy đủ hơn. Khi bấm “Đăng nhập Facebook”, một cửa sổ trình duyệt sẽ mở trên máy đang chạy app để bạn tự đăng nhập — app không thấy mật khẩu, chỉ lưu phiên trên máy. (Chạy app trên máy của bạn thì mới thấy cửa sổ này; nếu app chạy trên máy chủ khác, hãy chạy lệnh python fb_browser.py login trên máy đó.)

App chạy trên server không màn hình? Tải lên file phiên

Trên máy của bạn, bấm đúp dang-nhap-facebook.bat để đăng nhập và tạo file data/fb_state.json, rồi chọn file đó ở đây để nạp lên server.

Nên dùng tài khoản phụ: tài khoản dùng để cào có thể bị Facebook giới hạn hoặc khóa.
